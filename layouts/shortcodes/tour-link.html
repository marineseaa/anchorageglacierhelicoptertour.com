{{/* tour-link — inline affiliate link to a tour's OWN Viator page. Usage in content: {{< tour-link tour="2295HANGI" >}}Te Pa Tu{{< /tour-link >}} {{< tour-link tour="2295HANGI" />}} -> label falls back to the listing title Rule it exists for: every time body copy names a specific tour, the name links to that tour's Viator page (codified 2026-08-21, victoriafallshelicoptertours.com). Internal /tours/ links are for "read our breakdown"; the tour NAME is the affiliate link. Why a shortcode and not a Markdown link: js/main.js appends pid + mcid + campaign at runtime ONLY to anchors carrying data-affiliate-href. A plain [name](https://www.viator.com/...) opens the listing and earns nothing. This emits the bare URL as BOTH href (static fallback -- never a param'd URL in static HTML) and data-affiliate-href (what the JS decorates), plus the same rel the tour-page CTA uses. The URL is looked up from the offers JSON by id so it lives in one place. Unknown id -> build error, on purpose: a silent fallback would ship a dead or wrong-product link. string-compares both sides (Viator product codes are alphanumeric -- an int cast is a hard error here, not a rounding risk). THIS FILE MUST END IMMEDIATELY AFTER WITH NO TRAILING NEWLINE. A shortcode's output includes the file's final newline, which renders as a visible space before any punctuation that follows the link ("Pickup , from") and lands in the derived FAQPage answer text too. */}} {{- $site := .Site -}} {{- $id := .Get "tour" -}} {{- $tour := dict -}} {{- range (index $site.Data $site.Params.offersDataKey) -}} {{- if eq (string .id) (string $id) -}}{{- $tour = . -}}{{- end -}} {{- end -}} {{- $url := index (split ($tour.url | default "") "?") 0 -}} {{- $label := strings.TrimSpace (.Inner | default "") | default ($tour.title | default "") -}} {{- if not $url -}} {{- errorf "tour-link: tour %q not found in data/%s.json (page %s)" $id $site.Params.offersDataKey .Page.File.Path -}} {{- end -}} {{ .Page.RenderString $label }}
